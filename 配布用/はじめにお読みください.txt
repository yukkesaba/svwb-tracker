SVWB Tracker（Shadowverse: Worlds Beyond 戦績トラッカー）
==========================================================

Steam 版 Shadowverse: Worlds Beyond のランクマッチの戦績を、画面を読み取って自動で記録するツールです。
ゲームの操作やデータの書き換えは一切しません（画面を見て記録するだけです）。
非公式のファンメイドツールで、Cygames とは関係ありません。


■ 動作環境
- Windows 10 / 11（64bit）
- Windows の「日本語」言語パック（日本語版 Windows なら最初から入っています）
  ※ 文字の読み取りに Windows 標準の OCR を使います
- ゲームの画面比率が 16:9（1920x1080、2560x1440 など）


■ 使い方
1. この zip を好きな場所に展開します（「Program Files」以外がおすすめ）
2. フォルダの中の「SVWB Tracker.exe」を起動します
   ※ 初回は「Windows によって PC が保護されました」と出ることがあります。
     「詳細情報」→「実行」で起動できます（署名していないため出る表示です）
3. ゲームを起動してランクマッチを遊ぶと、試合ごとに自動で記録されます
   - 勝敗・先攻/後攻・相手クラス・使用デッキ・ランク・獲得MP・CR（変動）
   - 記録の日時は試合開始の時刻です
4. 監視中はウィンドウを閉じてもタスクトレイで動き続けます。終了はウィンドウ右上の「終了」ボタンか、トレイアイコンの右クリック →「終了」

デッキ名は画面から読み取りますが、まれに読み間違えます。
「＋ 登録」でデッキ名を登録しておくと、読み崩れても登録した名前に揃えて記録します。
間違った記録は「履歴」タブから編集・削除できます。
記録時の通知は「設定」の「通知を表示する」でオフにできます。
デッキ名が増えてきたら「デッキ整理」で、名前の変更・統合や、使わなくなったデッキを隠すことができます。
「相性」タブでは、自分のデッキと相手クラスの組み合わせごとの勝率を見られます。


■ 配信で使う（OBS など）
「設定」の「配信用の表示を書き出す」をオンにすると、今日の戦績を data\obs フォルダに書き出します。
試合のたびに自動で表示が変わります。「設定」の「配信用フォルダを開く」でフォルダを開けます。

・デザインした表示（OBS の「ブラウザ」ソース）
  3 種類あります。どれか（複数でも可）を選んでください。背景は透明です。
    bar.html      帯。今日の勝敗・勝率・CR・直近10戦（目安の大きさ 幅 700 × 高さ 100）
    card.html     カード。勝率のリング・連勝・デッキ名（幅 320 × 高さ 220）
    minimal.html  背景なしの文字だけ（幅 320 × 高さ 160）
  1. OBS の「ソース」の「＋」→「ブラウザ」
  2. 「ローカルファイル」にチェックを入れ、data\obs の中の上のファイルを選ぶ
  3. 幅と高さを上の目安にする
  「今使っているデッキの戦績だけを出す」をオンにすると、直前の試合のデッキで今日戦った分だけを数えます。
  デッキを替えて試合をすると、そのデッキの数字に切り替わります。
  色や大きさは、同じ画面の「カスタム CSS」で変えられます。例:
    :root { --win: #22c55e; --loss: #ef4444; }   勝ち・負けの色
    :root { --size: 64px; }                       minimal.html の文字の大きさ
  使える名前は各 HTML ファイルの先頭に書いてあります。

・文字だけの表示（OBS の「テキスト」ソース）
  テキストソースで「ファイルから読み取り」に data\obs\today.txt を指定します。
  書式は設定で変えられます（例: {wins}勝 {losses}敗 勝率{rate}%）。使える名前は書式の欄にマウスを乗せると出ます。


■ データの場所
戦績・設定・スクリーンショット・ログは、exe と同じフォルダの「data」フォルダに保存されます。
リザルト画面のスクリーンショットは新しい順に 500 枚まで残し、古いものから自動で消します（戦績は消えません）。
枚数は「設定」の「残すリザルト画面」で変えられます（0 で無制限）。
新しい版に更新するときは、「data」フォルダを新しい版のフォルダにコピーしてください。
アンインストールはフォルダごと削除するだけです。


■ うまく記録されないとき
- 報告のときは、ウィンドウ左上に出ているバージョン（v1.1.0 など）も教えてください
- ゲームのウィンドウが最小化されているときや、ほかのウィンドウで隠れているときは読み取れません
- ウィンドウモードでも記録できますが、ゲームの画面が 1920x1080 より小さいとデッキ名とランクを読み間違えやすくなります
- 「data\tracker.log」と「data\debug」の画像を添えて報告してもらえると原因を調べられます
